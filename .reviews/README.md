# Reviews Directory

This directory contains review artifacts and feedback documents that don't belong in the main documentation tree.

## Structure

- `*.md` - Review response documents
- `*-comments.txt` - Inline review comments
- `archived/` - Old review materials after incorporation

## Workflow

1. Draft design document in `docs/`
2. Review comments go here in `.reviews/`
3. After incorporation, archive review materials
4. Final design stays in `docs/`

This keeps `docs/` clean and focused on current documentation rather than review history.
