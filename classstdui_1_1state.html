Detailed Description

template<class T>
class stdui::state< T >

Handle to framework-managed persistent state storage.

A state<T> handle is not ordinary local C++ storage. It is a reference to persistent storage keyed by component identity and state slot. The actual value survives re-evaluation of view expressions.
