stdui

stdui is an experimental modern declarative UI framework for C++.

The public API is header-only and targets C++20. The framework separates view expressions from persistent runtime state, keeps layout generic, and treats rendering, interaction, semantics, and text as specialized subsystems.

API Areas

  • Expression DSL and components: stdui::component
  • Reconciliation and local state: stdui::runtime
  • Generic layout primitives: stdui::layout_hstack, stdui::layout_vstack, stdui::layout_grid, stdui::layout_overlay
  • Logical geometry: stdui::rect

See the repository README.md for build, install, test, and coverage commands.
