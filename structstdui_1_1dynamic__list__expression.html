Detailed Description

template<class Range, class IdFn, class BodyFn>
struct stdui::dynamic_list_expression< Range, IdFn, BodyFn >

A runtime-sized list of expressions identified by an id function.

IdFn receives one item and returns an explicit id. BodyFn receives one item and returns another view expression.
